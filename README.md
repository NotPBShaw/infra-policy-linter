# Infra Policy Linter

Infrastructure policy checks with structured findings.

![CI](https://github.com/NotPBShaw/infra-policy-linter/actions/workflows/ci.yml/badge.svg)

Go CLI for scanning infrastructure-as-code resources against policy rules.

## Features
- JSON input for resources.
- Rule-based validation.
- Structured scan reports.
- Unit tests and CI.

## Quickstart

```bash
go test ./...
```
